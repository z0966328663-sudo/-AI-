#我的 AI 每日飲食教練

我想學：認識食物中的營養，並學會安排比較均衡的一餐。

我以前卡在：不確定哪些食物富含蛋白質，也不知道一天要注意哪些營養；常聽到「先吃菜、再吃蛋白質、最後吃主食」，但不清楚怎麼應用在自己的餐點。

我現在的程度，以及我怎麼測的：目前能說出雞蛋、肉類和豆腐含有蛋白質，但不太會判斷其他食物的營養，也不熟悉營養標示。第一週先做 10 題食物分類與營養標示小測驗，記錄答對題數，也試著分析一天的一餐。

5 週後我要做到：能辨認常見的蛋白質食物和主要食物類別，看懂基本營養標示，並能說明一餐如何搭配得更均衡。再做一次類似的小測驗，比較前後成績。

我練習的場景、時間和每週次數：在家吃飯或買便當時練習，每次 10～15 分鐘，每週 4 次。

那個時候我有空的感官：主要用看的和讀文字；有空時也可以聽 AI 說明或朗讀練習題。

我的產品會怎麼幫我：做一個打開就能練習的「我的每日飲食學習助手」：每天提供一個食物分類、營養標示判讀或餐點搭配小任務，附簡短說明與即時答案回饋，並記錄每週答題成果。
